title: Context
description: Data that survives transitions.

## Define

Needs [checkout.ts](https://github.com/anderscan/mantaq/blob/main/apps/docs/src/content/docs/checkout.ts) and `@mantaq/sugar`.

```ts
import type { CheckoutContext } from "./checkout";

const initialContext: CheckoutContext = {};
```

## Read and write

- `get()` returns the live record; mutate it, then `set()`
- Any `set()` triggers `change`, even with the same reference

```ts
import { Actor } from "@mantaq/core";
import { basicInfo, shippingAddress, submitBasicInfo } from "./checkout";

const checkout = Actor({
  inputs: [submitBasicInfo],
  states: [basicInfo, shippingAddress],
  initial: basicInfo,
  context: initialContext,
  setup: (m) => {
    m.on(basicInfo, {
      event: submitBasicInfo,
      to: [shippingAddress],
      handler: (event, { context }) => {
        const s = context.get();
        s.basicInfo = event.payload;
        context.set(s);
        return { state: shippingAddress };
      },
    });
  },
});

checkout.send(submitBasicInfo.create({ email: "a@b.com", name: "A" }));
```

## Read outside transitions

```ts
checkout.context.basicInfo?.email; // "a@b.com"
```

## Effects

Effects get the same handle. Regions have their own context.
