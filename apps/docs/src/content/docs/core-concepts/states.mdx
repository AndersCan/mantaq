State. Node in graph. `state(id)()` makes one.

## Basic states

```ts
import { state } from "@mantaq/core";

const idle = state("idle")();
const loading = state("loading")();
const success = state("success")();

idle.name; // "idle"
idle.isFinal; // false
```

## Final states

Mark state done. Signal completion.

```ts
const done = state("done")().final();
done.isFinal; // true
```

Actor enters final state → `"done"` subscribers fire.

## Hierarchical states (regions)

Sub-actors. Passed as `regions` to the Actor constructor. Child runs concurrently.

```ts
const healthMonitor = new Actor({
  inputs: [healthCheckResult],
  states: [unknown, healthy, degraded],
  initial: unknown,
  setup: (m) => {
    m.on(unknown, healthCheckResult, (event) => ({
      state: event.healthy ? healthy : degraded,
    }));
  },
});

const manager = new Actor({
  inputs: [connect],
  internal: [healthCheckResult],
  states: [disconnected, connected],
  initial: disconnected,
  regions: { health: healthMonitor }, // child named "health"
  setup: (m) => {
    m.on(connected, healthCheckResult, (event) => {
      manager.regions.health.send(healthCheckResult.create({ healthy: event.healthy }));
      return {};
    });
  },
});
```

Snapshot. Nested.

```ts
// { path: ["connected"], context: {...}, regions: { health: { path: ["healthy"], context: {...}, regions: {} } } }
```

## Parallel states

Multiple regions. Run same time.

```ts
const playerState = state("player")();
const player = new Actor({
  inputs: [playToggle, muteToggle],
  states: [playerState],
  initial: playerState,
  regions: {
    playback: playbackActor,
    audio: audioActor,
  },
  setup: () => {},
});
```

Each region is its own actor. `matches(player, "player.playback.playing")` checks a specific region's state.

## Payloads

States carry optional payload. Type it at creation.

```ts
const loading = state("loading")<{ taskId: string }>();
const success = state("success")<{ data: string }>();

// In transition handler:
return { state: success.create({ data: result }) };
```

Effects read it: `state.payload`. Typed from the state ref.
