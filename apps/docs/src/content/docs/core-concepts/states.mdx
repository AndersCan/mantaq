## What

A state is a named, typed node in the machine's graph. `state("basicInfo")()`
creates one.

State is not data. Data lives in [Context](/mantaq/core-concepts/context/).
State answers "where am I?". Context answers "what do I know?".

## Basic states

The examples on this page build on each other: paste them into one file, in order.

```ts
import { state } from "@mantaq/core";

const basicInfo = state("basicInfo")();
const submitting = state("submitting")();
basicInfo.name; // "basicInfo"
basicInfo.isFinal; // false
```

## Final states

```ts
const success = state("success")().final();
success.isFinal; // true
```

Entering a final state fires `"done"` subscribers, sets `snapshot().done` to
`true`, and stops the actor from accepting events.

## Payloads

States carry an optional payload, passed on entry, read by effects.

```ts
import { Actor, event } from "@mantaq/core";

const error = state("error")<{ reason: string }>();
const paymentFail = event("paymentFail")<{ reason: string }>();

const payments = Actor({
  inputs: [paymentFail],
  states: [submitting, error],
  initial: submitting,
  setup: (m) => {
    m.on(submitting, {
      event: paymentFail,
      to: [error],
      handler: (event) => ({ state: error, payload: { reason: event.payload.reason } }),
    });
    m.effect(error, {
      name: "logFailure",
      fn: ({ state }) => {
        console.log(state.payload.reason);
      },
    });
  },
});

payments.send(paymentFail.create({ reason: "card declined" })); // logs "card declined"
```

## Regions (hierarchical states)

Sub-actors passed as `regions` to the Actor constructor. Child runs alongside
parent. Snapshot nests.

```ts
import { matches } from "@mantaq/sugar";

const scanning = state("scanning")();
const cleared = state("cleared")();
const flagged = state("flagged")();
const scanDone = event("scanDone")<{ risky: boolean }>();

const fraudMonitor = Actor({
  inputs: [scanDone],
  states: [scanning, cleared, flagged],
  initial: scanning,
  setup: (m) => {
    m.on(scanning, {
      event: scanDone,
      to: [cleared, flagged],
      handler: (event) => ({ state: event.payload.risky ? flagged : cleared }),
    });
  },
});

const checkout = Actor({
  inputs: [],
  states: [basicInfo],
  initial: basicInfo,
  setup: () => {},
  regions: { fraud: fraudMonitor },
});

fraudMonitor.send(scanDone.create({ risky: false }));
matches(checkout, "basicInfo.fraud.cleared"); // true
```

`matches(checkout, "basicInfo.fraud.cleared")` checks a child state.

Multiple regions run simultaneously: `regions: { fraud: fraudMonitor, analytics: analyticsMonitor }`.

Each is its own actor. Both run independently.
