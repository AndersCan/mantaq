## Create

Needs [checkout.ts](https://github.com/anderscan/mantaq/blob/main/apps/docs/src/content/docs/checkout.ts) and `@mantaq/sugar`.

```ts
import { createCheckoutActor } from "./checkout";

const { actor: checkout } = createCheckoutActor();
```

```
basicInfo -> shippingAddress -> payment -> submitting -> success
                  ^ (back) v                   v (back)
                                              error
```

## Send events

```ts
import { submitBasicInfo } from "./checkout";

checkout.send(submitBasicInfo.create({ email: "a@b.com", name: "A" }));
```

## Check state

```ts
import { matches } from "@mantaq/sugar";

checkout.snapshot().path[0]; // "shippingAddress"
matches(checkout, "shippingAddress"); // true
```

## Listen

```ts
const unsub = checkout.on("change", {
  fn: (snap) => console.log(snap.path),
});
unsub(); // stop listening
```

Fires at once, then on every change.

## Settled

```ts
await checkout.settled();
```

Waits for internal events and effects.

## Snapshot

```ts
checkout.snapshot();
// { path: ["shippingAddress"], context: { basicInfo: {...} }, regions: {} }
```

## Options

| Option           | Type                                |
| ---------------- | ----------------------------------- |
| `inputs`         | `EventRef[]`                        |
| `outputs`        | `EventRef[]`                        |
| `internal`       | `EventRef[]`                        |
| `states`         | `StateRef[]`                        |
| `initial`        | `StateRef` or `{ state, payload? }` |
| `context`        | `ActorContext`                      |
| `clock`          | `Clock`                             |
| `setup`          | `(m: ActorBuilder) => void`         |
| `regions`        | `Record<string, AnyActor>`          |
| `internalBudget` | `number`                            |

## Setup

| Method                                 |
| -------------------------------------- |
| `m.on(state, { event, to, handler })`  |
| `m.onAny({ event, to, handler })`      |
| `m.effect(state, { name, sends, fn })` |

Handlers return `{ state }`, or `{}` to stay.
