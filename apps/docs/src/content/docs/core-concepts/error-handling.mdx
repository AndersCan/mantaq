## `snapshot().error`

| Field     | Meaning                                                                      |
| --------- | ---------------------------------------------------------------------------- |
| `error`   | thrown value                                                                 |
| `state`   | last good state                                                              |
| `context` | its context                                                                  |
| `event`   | trigger                                                                      |
| `reason`  | `transition`, `effect`, `unhandled`, `budget`, `output`, `internal`, `async` |

`send()` never throws: the machine dies to a terminal `__error` state and `snapshot().done` is `true`. Only the constructor throws. Queued events are dropped and later sends do nothing; throwing subscribers are swallowed.

## Catch and emit

Needs [checkout.ts](https://github.com/anderscan/mantaq/blob/main/apps/docs/src/content/docs/checkout.ts) and `@mantaq/sugar`.

```ts
import { Actor } from "@mantaq/core";
import { chargeCard, error, paymentFail, paymentOk, submitting, success } from "./checkout";

const payments = Actor({
  inputs: [],
  internal: [paymentOk, paymentFail],
  states: [submitting, success, error],
  initial: submitting,
  setup: (m) => {
    m.effect(submitting, {
      name: "chargeCard",
      sends: [paymentOk, paymentFail],
      fn: ({ signal, emit }) => {
        chargeCard("4242 4242 4242 4242")
          .then((id) => {
            if (!signal.aborted) emit(paymentOk.create({ orderId: id }));
          })
          .catch((r) => {
            if (!signal.aborted) emit(paymentFail.create({ reason: String(r) }));
          });
      },
    });
    m.on(submitting, { event: paymentOk, to: [success], handler: () => ({ state: success }) });
    m.on(submitting, { event: paymentFail, to: [error], handler: () => ({ state: error }) });
  },
});
```

## `on("error")`

Replays to late subscribers.

```ts
import { createCheckoutActor, payment } from "./checkout";

const { actor: checkout } = createCheckoutActor();

checkout.on("error", {
  fn: (info) => {
    console.error(`${info.reason} on ${info.event.type}:`, info.error);
  },
});
```

## `recover()`

Breaks determinism; effects do not restart.

```ts
checkout.recover({ state: payment, context: { paymentInfo: { cardNumber: "..." } } });
```

## Dead vs failed

- **Dead:** `"__error"`. Recreate the actor.
- **Failed:** a modelled `error` state. Render it normally.

```ts
checkout.on("change", {
  fn: () => {
    console.log(checkout.state.name); // "basicInfo"
  },
});
```

Never call `recover()` from a UI.
