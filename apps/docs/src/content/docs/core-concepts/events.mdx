---
title: Events
description: Messages that trigger transitions.
---

Event. Typed message. Triggers transition. `event(id)()` makes one.

## Basic events

```ts
import { event } from "@mantaq/core";

const start = event("START")();
const fetchData = event("FETCH")<{ url: string }>();

start.id; // "START"
```

Payload must be `object | void`. No payload by default.

## Create instances

```ts
start.create(); // { id: "START" }
fetchData.create({ url: "/api" }); // { id: "FETCH", url: "/api" }
```

## Check identity

```ts
start.is(someEvent); // boolean
```

`someEvent.id === "START"`.

## Use in transitions

```ts
const actor = new Actor({
  inputs: [start, fetchData],
  states: [idle, loading],
  initial: idle,
  setup: (m) => {
    m.on(idle, start, () => ({ state: loading }));
    m.on(idle, fetchData, (event, { context }) => {
      const s = context.get();
      context.set({ ...s, url: event.url });
      return { state: loading };
    });
  },
});
```

Handler gets typed event object.

## Internal events

Events from effects. Processed after current transition.

```ts
const authDone = event("AUTH_DONE")();

const actor = new Actor({
  inputs: [login],
  internal: [authDone],
  // ...
  setup: (m) => {
    m.effect(authenticating, ({ signal, emit }) => {
      authenticate().then((result) => {
        if (!signal.aborted) emit(authDone.create());
      });
    });
  },
});
```

## Any handler

`m.onAny` intercepts an event in every state.

```ts
setup: (m) => {
  m.onAny(cancel, (_event, { context }) => {
    const s = context.get();
    context.set({ ...s, cancelled: true });
    return { state: cancelled };
  });
  m.on(idle, start, () => ({ state: running }));
},
```

State-specific runs first. `onAny` runs after — and only transitions if no
state-specific handler fired. Its `emit` still queues.
