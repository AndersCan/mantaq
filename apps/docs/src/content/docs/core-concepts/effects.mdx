## EffectInput

```ts
{
  signal: AbortSignal;
  state: { name: string; payload: unknown };
  event: InternalEvent;
  context: Context<ActorContext>;
  emit: (event) => void;
  clock: Clock;
}
```

## Rules

- Run on every entry, initial state included (`event.type` is `"__init"`)
- Terminal states run entry effects too
- Never throw: catch and emit an internal error event

## Auto-abort

`signal` fires when the actor leaves the state. Examples: [checkout machine](https://github.com/anderscan/mantaq/blob/main/apps/docs/src/content/docs/checkout.ts).

```ts
m.effect(submitting, {
  name: "chargeCard",
  fn: ({ signal, emit, context }) => {
    const cardNumber = context.get().paymentInfo?.cardNumber ?? "";
    chargeCard(cardNumber).then((orderId) => {
      if (!signal.aborted) emit(paymentOk.create({ orderId }));
    });
  },
});
```

## `sends`

```ts
m.effect(submitting, {
  name: "chargeCard",
  sends: [paymentOk, paymentFail, paymentTimeout],
  fn: ({ signal, emit, context }) => {
    const cardNumber = context.get().paymentInfo?.cardNumber ?? "";
    chargeCard(cardNumber).then((orderId) => {
      if (!signal.aborted) emit(paymentOk.create({ orderId }));
    });
  },
});
```

`emit` accepts only listed events; without `sends` it is untyped. The [diagram](/mantaq/core-concepts/diagrams/) reads `sends`.

## Multiple effects

```ts
m.effect(submitting, {
  name: "chargeCard",
  sends: [paymentOk, paymentFail],
  fn: ({ signal, emit, context }) => {
    const cardNumber = context.get().paymentInfo?.cardNumber ?? "";
    chargeCard(cardNumber).then(
      (id) => {
        if (!signal.aborted) emit(paymentOk.create({ orderId: id }));
      },
      (err) => {
        if (!signal.aborted) emit(paymentFail.create({ reason: String(err) }));
      },
    );
  },
});
m.effect(submitting, {
  name: "startSubmitTimeout",
  sends: [paymentTimeout],
  fn: ({ signal, emit, clock }) => {
    clock.setTimeout(800, { signal, cb: () => emit(paymentTimeout.create()) });
  },
});
```

## Error handling

An uncaught error ends in `__error`: see [Error Handling](/mantaq/core-concepts/error-handling/).
