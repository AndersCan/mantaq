---
title: Effects
description: Side effects on state entry.
---

Effect. Runs on state entry. Gets `EffectInput`. Can emit events.

Register effects in `setup` with `m.effect(state, fn)`.

## Basic effect

```ts
const actor = new Actor({
  // ...
  setup: (m) => {
    m.effect(loading, ({ signal, emit }) => {
      fetch("/api")
        .then((res) => res.json())
        .then((data) => {
          if (!signal.aborted) emit({ type: "FETCH_DONE", payload: data });
        });
    });
  },
});
```

## EffectInput

```ts
{
  signal: AbortSignal;           // abort on state exit
  state: { name: string; payload: unknown };  // payload typed from state ref
  event: InternalEvent;  // trigger event (created instance)
  context: Context<ActorContext>; // handle: get() reads, set() replaces
  emit: (event) => void;        // emit event: internal, input, or output
  clock: Clock;                 // timers
}
```

## Auto-abort

Effect aborts. Actor leaves state.

```ts
setup: (m) => {
  m.effect(loading, ({ signal, clock }) => {
    const id = clock.setTimeout(5000, () => {
      // timeout
    }, { signal });
    // No manual clear. AbortSignal handles it.
  });
},
```

## Multiple effects

Call `m.effect` multiple times for the same state. Runs in order.

```ts
setup: (m) => {
  m.effect(active, ({ signal }) => { /* one */ });
  m.effect(active, ({ signal }) => { /* two */ });
},
```

## Error handling

Never throw in an effect. Catch errors and emit an internal error event; a
transition handles it.

```ts
setup: (m) => {
  m.effect(loading, ({ signal, emit }) => {
    fetch("/api")
      .then((res) => res.json())
      .catch((err) => {
        if (!signal.aborted) emit({ type: "FETCH_FAILED", payload: error: String(err) });
      });
  });
},
```

Tip: `@mantaq/sugar` provides `withPromise` and `withTimeout` helpers for common effect patterns. See [Sugar](/mantaq/sugar/effect-helpers/).
