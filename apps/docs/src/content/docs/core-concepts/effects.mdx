---
title: Effects
description: Side effects on state entry.
---

Effect. Runs on state entry. Gets `EffectInput`. Can emit events.

## Basic effect

```ts
const actor = new Actor({
  // ...
  effects: {
    loading: [
      ({ signal, emit }) => {
        fetch("/api")
          .then((res) => res.json())
          .then((data) => {
            if (!signal.aborted) emit({ id: "FETCH_DONE", data });
          });
      },
    ],
  },
});
```

## EffectInput

```ts
{
  signal: AbortSignal;           // abort on state exit
  state: { name: string; payload: unknown };  // current state + payload
  event: { id: string } & Record<string, unknown>;  // trigger event (created instance)
  context: ActorContext;         // mutable context
  emit: (event) => void;        // emit internal event
  clock: Clock;                 // timers
}
```

## Auto-abort

Effect aborts. Actor leaves state.

```ts
effects: {
  loading: [
    ({ signal, clock }) => {
      const id = clock.setTimeout(5000, () => {
        // timeout
      }, { signal });
      // No manual clear. AbortSignal handles it.
    },
  ],
}
```

## Multiple effects

Array. Runs sequential.

```ts
effects: {
  active: [
    ({ signal }) => { /* one */ },
    ({ signal }) => { /* two */ },
  ],
}
```

## Error handling

Effect error → `"error"` subscriber.

```ts
actor.on("error", (err) => {
  console.error("Effect failed:", err);
});
```

One effect error. Others still run.

Tip: `@mantaq/sugar` provides `withPromise` and `withTimeout` helpers for common effect patterns. See [Sugar](/mantaq/sugar/effect-helpers/).
