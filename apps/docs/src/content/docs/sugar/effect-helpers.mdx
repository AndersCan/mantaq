---
title: Effect Helpers
description: Promise bridging and timeout helpers for effects.
---

Effects need patterns. Promise bridging. Timeouts. Sugar provides two.

Register effects in `setup` with `m.effect(state, fn)`.

## withPromise

Bridge promise to actor events. Abort-safe.

```ts
import { withPromise } from "@mantaq/sugar";

setup: (m) => {
  m.effect(loading, ({ signal, emit }) => {
    withPromise(fetch("/api"), signal, emit, {
      success: (data) => ({ type: "FETCH_DONE", payload: data }),
      error: (err) => ({ type: "FETCH_ERROR", payload: err }),
    });
  });
},
```

### What it does

1. Awaits promise
2. On resolve → calls `success` → emits resulting event
3. On reject → calls `error` → emits resulting event
4. Checks `signal.aborted` before emitting

Without sugar:

```ts
setup: (m) => {
  m.effect(loading, ({ signal, emit }) => {
    fetch("/api")
      .then((data) => {
        if (!signal.aborted) emit({ type: "FETCH_DONE", payload: data });
      })
      .catch((err) => {
        if (!signal.aborted) emit({ type: "FETCH_ERROR", payload: err });
      });
  });
},
```

Same logic. More code. Easy to forget abort check.

### Mapper functions

```ts
withPromise(promise, signal, emit, {
  success: (data) => ({ type: "DONE", payload: data }), // must return envelope: { type, payload? }
  error: (err) => ({ type: "FAIL", payload: err }), // same
});
```

Return value emitted as an event. Actor dispatches it (internal/input → transition, else output).

## withTimeout

Timeout via actor's clock. Abort-safe.

```ts
import { withTimeout } from "@mantaq/sugar";

setup: (m) => {
  m.effect(waiting, (input) => {
    withTimeout(5000, input, () => ({ type: "TIMEOUT" }));
  });
},
```

### What it does

1. Schedules timeout on actor's clock
2. On fire → checks `signal.aborted` → calls `eventFn` → emits resulting event
3. State exit aborts the effect signal → no emit after exit

Warns on invalid `ms`.

Without sugar:

```ts
setup: (m) => {
  m.effect(waiting, ({ clock, signal, emit }) => {
    clock.setTimeout(5000, () => {
      if (!signal.aborted) emit({ type: "TIMEOUT" });
    });
  });
},
```

Sugar checks the signal for you.

### VirtualClock testing

```ts
import { Actor, VirtualClock, event, state } from "@mantaq/core";
import { withTimeout } from "@mantaq/sugar";

const idle = state("idle")();
const waiting = state("waiting")();
const start = event("START")();
const clock = new VirtualClock();

const actor = new Actor({
  inputs: [start],
  states: [idle, waiting],
  initial: idle,
  clock,
  setup: (m) => {
    m.on(idle, start, () => ({ state: waiting }));
    m.effect(waiting, (input) => withTimeout(5000, input, () => ({ type: "TIMEOUT" })));
  },
});

actor.send(start.create());
clock.advance(5000); // triggers timeout
```

Deterministic. Same as core, less boilerplate.

## Abort safety

Both helpers check `signal.aborted`. State exit aborts effect.

Promise resolves after state exit → no emit. Timer fires after exit → no emit.

No manual checks needed. Sugar handles it.
