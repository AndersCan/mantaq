title: Effect Helpers
description: Promise bridging and timeout helpers for effects

## What

`withPromise()` bridges a promise to actor events. `withTimeout()` arms a
timeout that fires an event. Both check `signal.aborted` before emitting, so
promises resolving after state exit and timers firing after exit produce no
side effects. Both use the actor's clock, so tests stay deterministic on
`VirtualClock`.

## withPromise

```ts
withPromise(promise, signal, emit, {
  success: (data) => ({ type: "paymentOk", payload: data }),
  error: (err) => ({ type: "paymentFail", payload: err }),
});
```

- Awaits the promise
- On resolve: calls `success`, emits resulting event
- On reject: calls `error`, emits resulting event
- Checks `signal.aborted` before each emit
- Mapper return value must be `{ type, payload? }` envelope

Sugar equivalent:

```ts
setup: (m) => {
  m.effect(submitting, {
    name: "chargeCard",
    fn: (input) => {
      const s = input.context.get();
      withPromise(chargeCard(s.paymentInfo!.cardNumber), input.signal, input.emit, {
        success: (orderId) => paymentOk.create({ orderId }),
        error: (reason) => paymentFail.create({ reason: String(reason) }),
      });
    },
  });
};
```

### Errors as values

When the port returns `Promise<Either<PaymentError, string>>`, map the result with `Either.match` (from `@mantaq/utils`) inside `success`. No extra helper is needed and neither branch needs a cast:

```ts
type PaymentEvent =
  | { type: "paymentOk"; payload: { orderId: string } }
  | { type: "paymentFail"; payload: { reason: string } };

m.effect(submitting, {
  name: "chargeCard",
  fn: (input) => {
    const s = input.context.get();
    withPromise(chargeCard(s.paymentInfo!.cardNumber), input.signal, input.emit, {
      success: (result) =>
        Either.match(result, {
          onLeft: (reason): PaymentEvent => paymentFail.create({ reason: reason.message }),
          onRight: (orderId): PaymentEvent => paymentOk.create({ orderId }),
        }),
      error: (reason) => paymentFail.create({ reason: String(reason) }),
    });
  },
});
```

Annotating both handlers with the event union lets `Either.match` infer one result type.

## withTimeout

```ts
withTimeout(ms, input, () => paymentTimeout.create());
```

- Schedules timeout on the actor's clock
- On fire: checks `signal.aborted`, calls `eventFn`, emits resulting event
- State exit aborts the effect signal, no emit after exit
- Warns on invalid `ms`

Equivalent without sugar:

```ts
m.effect(submitting, ({ clock, signal, emit }) => {
  clock.setTimeout(800, () => {
    if (!signal.aborted) emit(paymentTimeout.create());
  });
});
```

## VirtualClock testing

```ts
import { checkout } from "../checkout.ts";
import { VirtualClock } from "@mantaq/core";

const clock = VirtualClock();
checkout.send(submitPayment.create());
clock.advance(800); // triggers timeout synchronously
matches(checkout, "error"); // true: no answer in 800ms
```

Same clock, same inputs, same trace.
