`states()` and `events()`. Batch create. One call, typed record.

Checkout machine from [Actors](/mantaq/core-concepts/actors/). Its six states, its seven events — created in two calls.

## Without sugar

```ts
import { state, event } from "@mantaq/core";

const basicInfo = state("basicInfo")();
const shippingAddress = state("shippingAddress")();
const payment = state("payment")();
const submitting = state("submitting")();
const success = state("success")().final();
const error = state("error")();

const submitBasicInfo = event("SUBMIT_BASIC_INFO")();
const submitShipping = event("SUBMIT_SHIPPING")();
const submitPayment = event("SUBMIT_PAYMENT")();
const back = event("BACK")();
const paymentOk = event("PAYMENT_OK")();
const paymentFail = event("PAYMENT_FAIL")();
const submittingDone = event("SUBMITTING_DONE")();
```

Thirteen calls. Repetitive.

## With sugar

```ts
import { states, events } from "@mantaq/sugar";

const { basicInfo, shippingAddress, payment, submitting, success, error } = states(
  "basicInfo",
  "shippingAddress",
  "payment",
  "submitting",
  "success",
  "error",
);

const {
  SUBMIT_BASIC_INFO,
  SUBMIT_SHIPPING,
  SUBMIT_PAYMENT,
  BACK,
  PAYMENT_OK,
  PAYMENT_FAIL,
  SUBMITTING_DONE,
} = events(
  "SUBMIT_BASIC_INFO",
  "SUBMIT_SHIPPING",
  "SUBMIT_PAYMENT",
  "BACK",
  "PAYMENT_OK",
  "PAYMENT_FAIL",
  "SUBMITTING_DONE",
);
```

Two calls. Typed names as keys.

## Return type

`states()` returns a typed record keyed by the literal names — `{ [K in T]: StateRef<K> }`. Not a plain `Record<string, ...>`.

`events()` same shape for `EventRef`.

Keys are the names you passed. Dot or bracket access:

```ts
const s = states("basicInfo", "payment", "success");
s.basicInfo; // StateRef<"basicInfo">
s["payment"]; // StateRef<"payment">

const e = events("SUBMIT_BASIC_INFO", "SUBMIT_PAYMENT");
e.SUBMIT_BASIC_INFO; // EventRef<"SUBMIT_BASIC_INFO">
```

Destructure or keep the record:

```ts
const s = states("basicInfo", "payment", "success");
const { basicInfo, payment, success } = s;
```

## Real example

Same checkout machine. Fewer lines.

```ts
import { Actor } from "@mantaq/core";
import { states, events } from "@mantaq/sugar";

const { basicInfo, payment, success } = states("basicInfo", "payment", "success");
const { SUBMIT_BASIC_INFO, SUBMIT_PAYMENT } = events("SUBMIT_BASIC_INFO", "SUBMIT_PAYMENT");

const checkout = new Actor({
  inputs: [SUBMIT_BASIC_INFO, SUBMIT_PAYMENT],
  states: [basicInfo, payment, success],
  initial: basicInfo,
  setup: (m) => {
    m.on(basicInfo, SUBMIT_BASIC_INFO, () => ({ state: payment }));
    m.on(payment, SUBMIT_PAYMENT, () => ({ state: success }));
  },
});
```

## Type safety

```ts
const { basicInfo, success } = states("basicInfo", "success");

// TypeScript knows:
basicInfo.name; // "basicInfo"
success.name; // "success"
success.final(); // isFinal = true
```

Names inferred as string literals.
