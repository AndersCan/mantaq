Static children via `regions`. Dynamic children need more.

Checkout story continues. Order placed. Now the shop fulfills it. Orders arrive
at runtime — how many, unknown. One worker per order. `ActorMap` tracks them.

## ActorMap

Registry. Spawn, kill, query children by ID.

```ts
import { ActorMap } from "@mantaq/sugar";

const orders = new ActorMap(shop);
```

Parent optional. With parent, child outputs forwarded to it. `new ActorMap()` valid without parent — outputs stay local.

### Order workers

```ts
const picking = state("picking")();
const shipped = state("shipped")();
const open = state("open")();

const checkoutDone = event("CHECKOUT_DONE")<{ orderId: string }>();
const cancelAll = event("CANCEL_ALL")();
const ship = event("SHIP")();
const cancel = event("CANCEL")();

function createOrderWorker(orderId: string) {
  return new Actor({
    inputs: [ship, cancel],
    states: [picking, shipped],
    initial: picking,
    context: { orderId },
    setup: (m) => {
      m.on(picking, ship, () => ({ state: shipped }));
      m.on(picking, cancel, () => ({ state: picking }));
    },
  });
}
```

### Operations

```ts
orders.spawn("ord_1", () => createOrderWorker("ord_1")); // create child
orders.ensure("ord_1", () => createOrderWorker("ord_1")); // no-op, exists

orders.send("ord_1", ship.create()); // ship order 1
orders.kill("ord_1"); // remove child

orders.has("ord_1"); // boolean
orders.keys(); // []
```

### The shop parent

Checkout done → spawn a worker for the order. Cancel all → broadcast to every worker.

```ts
import { Actor, state, event } from "@mantaq/core";
import { ActorMap, broadcast } from "@mantaq/sugar";

const orders = new ActorMap();

const shop = new Actor({
  inputs: [checkoutDone, cancelAll],
  states: [open],
  initial: open,
  setup: (m) => {
    m.on(open, checkoutDone, (event) => {
      orders.ensure(event.payload.orderId, () => createOrderWorker(event.payload.orderId));
      return {};
    });
    m.onAny(cancelAll, () => {
      broadcast(orders, cancel.create());
      return {};
    });
  },
});
```

`ensure` spawns only if missing. Repeat `CHECKOUT_DONE` with same order id → no duplicate worker.

## broadcast

Send event to all children.

```ts
import { broadcast } from "@mantaq/sugar";

broadcast(orders, cancel.create());
```

Without sugar:

```ts
for (const id of orders.keys()) {
  orders.send(id, cancel.create());
}
```

## Factory function

Passed to `spawn` or `ensure`. Returns Actor.

```ts
orders.spawn("ord_2", () => createOrderWorker("ord_2"));
```

Factory runs at spawn time. New actor per call.

## Snapshot

`ActorMap.snapshot(key)` returns a single child's `Snapshot`, or `undefined` if the key is missing.

```ts
const snap = orders.snapshot("ord_1");
// { path: ["picking"], context: { orderId: "ord_1" }, regions: {} }
```

Get all children:

```ts
for (const key of orders.keys()) {
  const snap = orders.snapshot(key);
  // ...
}
```

## Cleanup

```ts
orders.kill("ord_1");
// Actor exits. Effects abort. Context gone.
```

No manual cleanup. Actor handles it.
