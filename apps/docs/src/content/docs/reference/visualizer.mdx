## `buildGraph(actor)`

```ts
function buildGraph(actor: AnyActor): ActorGraph;
```

Converts actor snapshot into graph nodes and edges.

### `ActorGraph`

| Property | Type          | What             |
| -------- | ------------- | ---------------- |
| `nodes`  | `GraphNode[]` | State nodes      |
| `edges`  | `GraphEdge[]` | Transition edges |

### `GraphNode`

| Property   | Type      | What              |
| ---------- | --------- | ----------------- |
| `id`       | `string`  | Node ID           |
| `label`    | `string`  | State name        |
| `isActive` | `boolean` | Currently active? |
| `isFinal`  | `boolean` | Terminal state?   |

### `GraphEdge`

| Property   | Type                 | What              |
| ---------- | -------------------- | ----------------- |
| `id`       | `string`             | Edge ID           |
| `source`   | `string`             | Source node ID    |
| `target`   | `string`             | Target node ID    |
| `label`    | `string`             | Event ID          |
| `isActive` | `boolean`            | Source is active? |
| `payload`  | `TransitionPayload?` | Guard/action info |

### `TransitionPayload`

| Property | Type                       | What                 |
| -------- | -------------------------- | -------------------- |
| `guard`  | `string?`                  | Guard condition text |
| `action` | `string?`                  | Emit action text     |
| `meta`   | `Record<string, unknown>?` | Extra metadata       |

## `collectActiveStates(snapshot, prefix, activeSet)`

```ts
function collectActiveStates(snapshot: Snapshot, prefix: string, activeSet: Set<string>): void;
```

Recursively collects active state IDs from a snapshot into the provided Set. Used internally by `buildGraph`.

---

## `actorGraphToFlow(graph, layoutOpts?)`

```ts
function actorGraphToFlow(
  graph: ActorGraph,
  opts?: LayoutOptions,
): { nodes: StateNode[]; edges: StateEdge[] };
```

Converts `ActorGraph` to React Flow compatible nodes and edges with automatic topological layout.

---

## `toReactFlowNodes(graphNodes, edges?, layoutOpts?)`

```ts
function toReactFlowNodes(
  nodes: GraphNode[],
  edges?: GraphEdge[],
  opts?: LayoutOptions,
): StateNode[];
```

Converts graph nodes to React Flow nodes. Positions computed via `computeNodePositions`. Pass edges and layout options to control layout.

---

## `toReactFlowEdges(graphEdges)`

```ts
function toReactFlowEdges(edges: GraphEdge[]): StateEdge[];
```

Converts graph edges to React Flow edges with `type: "state-edge"` and `data.isActive`, `data.payload`.

---

## `computeNodePositions(nodes, edges, opts?)`

```ts
function computeNodePositions(
  nodes: GraphNode[],
  edges: GraphEdge[],
  opts?: LayoutOptions,
): Map<string, { x: number; y: number }>;
```

Topological sort layout. Returns positions keyed by node ID.

### `LayoutOptions`

| Option              | Type           | Default | Description                    |
| ------------------- | -------------- | ------- | ------------------------------ |
| `direction`         | `"TB" \| "LR"` | `"TB"`  | Top-to-bottom or left-to-right |
| `nodeWidth`         | `number`       | `160`   | Node width for spacing         |
| `nodeHeight`        | `number`       | `60`    | Node height for spacing        |
| `horizontalSpacing` | `number`       | `220`   | Horizontal gap between levels  |
| `verticalSpacing`   | `number`       | `120`   | Vertical gap between nodes     |

## Components

### `<ActorFlow>`

React component. Renders an interactive graph with pan, zoom, minimap.

```tsx
<ActorFlow graph={graph} className="my-flow" style={{ height: 500 }} />
```

| Prop        | Type                  | Default | Description          |
| ----------- | --------------------- | ------- | -------------------- |
| `graph`     | `ActorGraph`          | —       | Graph data to render |
| `className` | `string`              | —       | Additional CSS class |
| `style`     | `React.CSSProperties` | —       | Inline styles        |

### `nodeTypes`

```ts
const nodeTypes = { state: StateNodeComponent };
```

Pre-configured React Flow node types. Pass to custom `ReactFlow` if building your own renderer.

### `edgeTypes`

```ts
const edgeTypes = { "state-edge": StateEdgeComponent };
```

Pre-configured React Flow edge types (`"state-edge"`). Shows edge labels with guard and action tags.
