## `buildGraph(actor)`

```ts
function buildGraph(actor: AnyActor): ActorGraph;
```

Converts actor snapshot into graph nodes and edges.

### `ActorGraph`

| Property | Type          | What             |
| -------- | ------------- | ---------------- |
| `nodes`  | `GraphNode[]` | State nodes      |
| `edges`  | `GraphEdge[]` | Transition edges |

### `GraphNode`

| Property   | Type      | What              |
| ---------- | --------- | ----------------- |
| `id`       | `string`  | Node ID           |
| `label`    | `string`  | State name        |
| `isActive` | `boolean` | Currently active? |
| `isFinal`  | `boolean` | Terminal state?   |

### `GraphEdge`

| Property   | Type                 | What              |
| ---------- | -------------------- | ----------------- |
| `id`       | `string`             | Edge ID           |
| `source`   | `string`             | Source node ID    |
| `target`   | `string`             | Target node ID    |
| `label`    | `string`             | Event ID          |
| `isActive` | `boolean`            | Source is active? |
| `payload`  | `TransitionPayload?` | Guard/action info |

### `TransitionPayload`

| Property | Type                       | What                 |
| -------- | -------------------------- | -------------------- |
| `guard`  | `string?`                  | Guard condition text |
| `action` | `string?`                  | Emit action text     |
| `meta`   | `Record<string, unknown>?` | Extra metadata       |

## `collectActiveStates(snapshot, prefix, activeSet)`

```ts
function collectActiveStates(snapshot: Snapshot, prefix: string, activeSet: Set<string>): void;
```

Recursively collects active state IDs from a snapshot into the provided Set. Used internally by `buildGraph`.

## `computeNodePositions(nodes, edges, opts?)`

```ts
function computeNodePositions(
  nodes: GraphNode[],
  edges: GraphEdge[],
  opts?: LayoutOptions,
): Map<string, { x: number; y: number }>;
```

Topological sort layout. Returns positions keyed by node ID.

### `LayoutOptions`

| Option              | Type           | Default | Description                    |
| ------------------- | -------------- | ------- | ------------------------------ |
| `direction`         | `"TB" \| "LR"` | `"TB"`  | Top-to-bottom or left-to-right |
| `nodeWidth`         | `number`       | `160`   | Node width for spacing         |
| `nodeHeight`        | `number`       | `60`    | Node height for spacing        |
| `horizontalSpacing` | `number`       | `220`   | Horizontal gap between levels  |
| `verticalSpacing`   | `number`       | `120`   | Vertical gap between nodes     |

## Components

### `<ActorFlow>`

React component wrapping an X6 `Graph`. Renders an interactive diagram with pan and zoom.

```tsx
<ActorFlow graph={graph} className="my-flow" style={{ height: 500 }} />
```

| Prop        | Type                  | Default | Description          |
| ----------- | --------------------- | ------- | -------------------- |
| `graph`     | `ActorGraph`          | —       | Graph data to render |
| `className` | `string`              | —       | Additional CSS class |
| `style`     | `React.CSSProperties` | —       | Inline styles        |
