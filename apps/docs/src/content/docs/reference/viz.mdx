The public API is the `<mantaq-viz>` web component and CSS custom properties. Functions below are internal to the package.

## `buildGraph(actor, internalIds?)`

```ts
function buildGraph(actor: AnyActor, internalIds?: Set<string>): ActorGraph;
```

Converts actor snapshot into graph nodes and edges.

### `ActorGraph`

| Property | Type          | What             |
| -------- | ------------- | ---------------- |
| `nodes`  | `GraphNode[]` | State nodes      |
| `edges`  | `GraphEdge[]` | Transition edges |

### `GraphNode`

| Property    | Type      | What              |
| ----------- | --------- | ----------------- |
| `id`        | `string`  | Node ID           |
| `label`     | `string`  | State name        |
| `isActive`  | `boolean` | Currently active? |
| `isFinal`   | `boolean` | Terminal state?   |
| `isInitial` | `boolean` | Initial state?    |

### `GraphEdge`

| Property         | Type                 | What                         |
| ---------------- | -------------------- | ---------------------------- |
| `id`             | `string`             | Edge ID                      |
| `source`         | `string`             | Source node ID               |
| `target`         | `string`             | Target node ID               |
| `label`          | `string`             | Event ID                     |
| `isActive`       | `boolean`            | Source is active?            |
| `isInternal`     | `boolean`            | Internal/effect?             |
| `isUndetermined` | `boolean`            | Target couldn't be resolved? |
| `payload`        | `TransitionPayload?` | Guard/action info            |

### `TransitionPayload`

| Property | Type                       | What                 |
| -------- | -------------------------- | -------------------- |
| `guard`  | `string?`                  | Guard condition text |
| `action` | `string?`                  | Emit action text     |
| `meta`   | `Record<string, unknown>?` | Extra metadata       |

## `collectActiveStates(snapshot, prefix, activeSet)`

```ts
function collectActiveStates(snapshot: Snapshot, prefix: string, activeSet: Set<string>): void;
```

Recursively collects active state IDs from a snapshot into the provided Set. Used internally by `buildGraph`.

## `computeNodePositions(nodes, edges, opts?)`

```ts
function computeNodePositions(
  nodes: GraphNode[],
  edges: GraphEdge[],
  opts?: LayoutOptions,
): Map<string, { x: number; y: number }>;
```

Dagre-based hierarchical layout. Returns positions keyed by node ID.

### `LayoutOptions`

| Option       | Type                                                   | Default    | Description                    |
| ------------ | ------------------------------------------------------ | ---------- | ------------------------------ |
| `direction`  | `"TB" \| "LR"`                                         | `"TB"`     | Top-to-bottom or left-to-right |
| `nodeWidth`  | `number`                                               | `160`      | Node width for spacing         |
| `nodeHeight` | `number`                                               | `60`       | Node height for spacing        |
| `nodesep`    | `number`                                               | `80`       | Horizontal gap between nodes   |
| `ranksep`    | `number`                                               | `160`      | Vertical gap between levels    |
| `router`     | `"normal" \| "orth" \| "manhattan" \| "metro" \| "er"` | `"normal"` | Edge routing algorithm         |

## `renderActorFlow(parent, options)`

```ts
function renderActorFlow(
  parent: HTMLElement,
  options: {
    graph: ActorGraph;
    layoutOptions?: LayoutOptions;
    onEdgeClick?: (eventName: string) => void;
  },
): ActorFlowInstance;
```

Creates an X6 graph in the parent element. Returns `ActorFlowInstance`.

### `ActorFlowInstance`

| Method                          | Description                  |
| ------------------------------- | ---------------------------- |
| `update(graph, layoutOptions?)` | Update the graph             |
| `destroy()`                     | Dispose X6 graph and cleanup |

## Components

### `<mantaq-viz>`

Web component for interactive state machine visualization.

```html
<mantaq-viz id="my-viz"></mantaq-viz>
```

```ts
const el = document.getElementById("my-viz");
el.actor = myActor;
```

| Property | Type       | Description        |
| -------- | ---------- | ------------------ |
| `actor`  | `AnyActor` | Actor to visualize |

Features:

- Toolbar with state display and event buttons
- Settings panel (direction, router, edge length)
- Pan and zoom via X6
- Auto-sync on actor state changes
- Transition animation (green flash on edge click)
- Node/edge tooltips with metadata
- Undetermined edge styling (red dashed)
