## What

A harness that wraps an actor, records every state, transition and effect a test drives through it, and asserts on that record.

## Why

A passing test says little about the transitions it never reached. The harness reports what the tests left uncovered, so a missing case shows up as a number.

## How

```ts
import { createTestHarness } from "@mantaq/test";

const harness = createTestHarness(meal);
harness.send(eat.create());
harness.assertStateVisited({ stateName: "full" });
harness.assertTransitionVisited({ from: "hungry", event: "eat" });
harness.coverage().percent.states; // 100
```

`meal` is the actor from the `@mantaq/core` page. Each assertion throws when it fails; `coverage()` lists what was never reached.

---

## `createTestHarness(actor)`

```ts
function createTestHarness<C>(actor: AnyActor<C>): TestHarness<C>;
```

Instruments actor for testing. Builds state graph, wraps `send` to record history.

```ts
const harness = createTestHarness(checkout);
harness.send(submitBasicInfo.create());
harness.assertStateVisited({ stateName: "shippingAddress" });
```

---

## `computeCoverage(graph, history)`

```ts
function computeCoverage(graph: ActorGraph, history: History): CoverageReport;
```

Compares graph against history. Returns state, transition, and effect coverage as totals, visited counts, and uncovered paths. Used internally by `harness.coverage()`.

```ts
const report = computeCoverage(graph, history);
report.percent.states; // 0–100
```

## `TestHarness`

```ts
interface TestHarness<C> {
  actor: AnyActor<C>;
  graph: ActorGraph;
  history: History;

  send(event: { type: string; payload?: unknown }): void;
  state: AnyActor["state"];
  snapshot(): Snapshot<C>;
  context: C | undefined;

  assertAllStatesVisited(): void;
  assertAllTransitionsVisited(): void;
  assertStateVisited(target: { stateName: string }): void;
  assertStateNeverVisited(banned: { stateName: string }): void;
  assertTransitionVisited(expected: { from: string; event: string }): void;
  assertTransitionNeverVisited(banned: { from: string; event: string }): void;
  assertContextNever(check: { predicate: (context: unknown) => boolean }): void;
  assertEffectRan(expected: { stateName: string; effectName: string }): void;
  assertEffectNeverRan(banned: { stateName: string; effectName: string }): void;

  wasStateVisited(stateName: string): boolean;
  wasTransitionVisited(expected: { from: string; event: string }): boolean;
  wasEffectRun(queried: { stateName: string; effectName: string }): boolean;

  coverage(): CoverageReport;
  reset(): void;
}
```

### Assert methods

All throw on failure.

| Method                                            | What                                                  |
| ------------------------------------------------- | ----------------------------------------------------- |
| `assertAllStatesVisited()`                        | Every graph node (non-`__initial__`) was hit          |
| `assertAllTransitionsVisited()`                   | Every graph edge (non-internal, non-undetermined) hit |
| `assertStateVisited({ stateName })`               | Named state was entered at least once                 |
| `assertStateNeverVisited({ stateName })`          | Named state was never entered                         |
| `assertTransitionVisited({ from, event })`        | `(from, event)` pair fired                            |
| `assertTransitionNeverVisited({ from, event })`   | Pair never fired                                      |
| `assertContextNever({ predicate })`               | Predicate does not match current context              |
| `assertEffectRan({ stateName, effectName })`      | Named effect of the state ran                         |
| `assertEffectNeverRan({ stateName, effectName })` | Named effect never ran                                |

### Query methods

Boolean checks, no throw.

| Method                                    | What              |
| ----------------------------------------- | ----------------- |
| `wasStateVisited(name)`                   | State entered?    |
| `wasTransitionVisited({ from, event })`   | Transition fired? |
| `wasEffectRun({ stateName, effectName })` | Effect ran?       |

## `CoverageReport`

```ts
interface CoverageReport {
  states: { total: number; visited: number; uncovered: string[] };
  transitions: {
    total: number;
    visited: number;
    uncovered: Array<{ from: string; event: string }>;
  };
  effects: { total: number; ran: number; unexecuted: string[] };
  percent: { states: number; transitions: number; effects: number };
}
```
