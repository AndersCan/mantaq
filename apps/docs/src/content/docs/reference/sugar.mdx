## `matches(actor, pattern)`

```ts
function matches(actor: { snapshot(): Snapshot }, pattern: string): boolean;
```

Dot-separated pattern. Snapshot tree.

```ts
matches(checkout, "payment"); // flat
matches(checkout, "basicInfo.fraud.scanning"); // hierarchical
matches(checkout, "basicInfo.fraud.cleared"); // parallel region
```

Prefix match. Checks top-level state name first, then descends only through region names in order. Ends at a state boundary. `matches(actor, "connected")` → true only if top-level state is `connected`. Not "anywhere inside" — that's `isIn`.

## `states(...entries)`

```ts
function states(
  ...entries: Array<string | { name: string; final?: boolean }>
): Record<string, StateRef>;
```

Batch state creation. Entries are strings, or objects with `final: true` for a
terminal state. `success` is final right at creation — no `.final()` call.

```ts
const s = states("basicInfo", "payment", { name: "success", final: true }, "error");
s.basicInfo.name; // "basicInfo"
s.success.isFinal; // true
```

## `events(...names)`

```ts
function events<T extends string>(...names: T[]): { [K in T]: EventRef<K> };
```

Batch event creation.

```ts
const e = events("submitBasicInfo", "submitPayment", "back");
e.submitBasicInfo.create(); // { type: "submitBasicInfo" }
```

## `tag(...stateRefs)`

```ts
function tag(...stateRefs: StateRef<string, unknown>[]): Tag;
```

Group states. `tag.has(snapshot)` → true if any active.

```ts
const busy = tag(s.payment, s.submitting);
busy.has(checkout.snapshot()); // true if paying or submitting
```

## `ActorMap`

Keyed registry of one actor type.

```ts
const map = new ActorMap(createOrderWorker);

map.spawn("ord_1");
map.spawn("ord_2");
map.send("ord_1", ship.create());
map.kill("ord_1");
```

`new ActorMap(factory, options?)` — `factory` builds the actor, receiving the
key: `(id: string) => Actor`. Every `spawn(key)` creates a fresh instance of
the same actor, keyed by id. `options: { autoReap? }` — `true` removes a child
once it reaches a final state (or dies into `__error`). Off by default;
completed children linger until `kill`.

| Method             | What                                   |
| ------------------ | -------------------------------------- |
| `spawn(key)`       | Fresh instance via the factory.        |
| `ensure(key)`      | No-op if exists.                       |
| `send(key, event)` | Send to child.                         |
| `kill(key)`        | Abort. Remove.                         |
| `has(key)`         | Exists?                                |
| `keys()`           | List keys.                             |
| `snapshot(key)`    | Child snapshot. `undefined` if absent. |
| `size`             | Count.                                 |

## `withPromise(promise, signal, emit, events)`

```ts
function withPromise<T>(
  promise: Promise<T>,
  signal: AbortSignal,
  emit: EmitFn,
  events: {
    success: (data: T) => InternalEvent;
    error: (err: unknown) => InternalEvent;
  },
): void;
```

Promise → actor events. Checks `signal.aborted`.
