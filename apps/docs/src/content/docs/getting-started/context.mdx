## What

Context is data the machine carries between states.

## Why

A state says where the person is, not what they have. The number of plates on the table belongs in context, so the states stay few.

## How

<Step n={5}>
  `serve` puts one more plate on the table: `plates` goes up and the person stays `hungry`.
</Step>
