## What

An effect runs while a state is active.

## Why

Work such as cooking belongs to a state, not to a click. Starting on entry and stopping on exit means a stale result never reaches a machine that has moved on.

## How

<Step n={7}>
  An effect runs when a state is entered and stops when it is left. In `cooking`, `cookMeal` answers
  `cooked`, which puts a plate on the table.
</Step>
