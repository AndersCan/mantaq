## What

A state is where the person is now. This tutorial models a meal; the first state is `hungry`.

## Why

A system that can be in many conditions at once turns into flags that disagree (`isHungry`, `isEating`, `isFull`). Naming each condition as one state means the machine is in exactly one of them.

## How

<Step n={1}>The meal starts in `hungry`.</Step>

```sh
npm create vite@latest my-app -- --template vanilla-ts
cd my-app && npm install
npm install @mantaq/core @mantaq/sugar
npm install -D vitest
```

Keep `strict` on; the examples rely on it. `tsconfig.json` has no `strict` line because TypeScript 6 and later turn it on by default. This prints `default: true` to confirm; if it prints `false`, add `"strict": true` under `compilerOptions`:

```sh
npx tsc --help --all | grep -A3 -x -- --strict | tail -1
```

The template also turns on `verbatimModuleSyntax`, so a type such as `Clock` needs `type` in its import, or `tsc` stops with TS1484. A machine factory that takes a clock starts with:

```ts
import { Actor, VirtualClock, type Clock } from "@mantaq/core";
```

Put each file from this guide in `src/`.
