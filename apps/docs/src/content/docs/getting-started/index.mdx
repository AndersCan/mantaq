## What

A state is where the person is now. This tutorial models a meal; the first state is `hungry`.

## Why

A system that can be in many conditions at once turns into flags that disagree (`isHungry`, `isEating`, `isFull`). Naming each condition as one state means the machine is in exactly one of them.

## How

<Step n={1}>The meal starts in `hungry`.</Step>

```sh
npm create vite@latest my-app -- --template vanilla-ts
cd my-app && npm install
npm install @mantaq/core @mantaq/sugar
npm install -D vitest
```

Keep `strict` on in `tsconfig.json`; the `vanilla-ts` template already runs strict (TypeScript turns it on by default), so do not set it to `false`. The examples rely on it. Put each file from this guide in `src/`.
