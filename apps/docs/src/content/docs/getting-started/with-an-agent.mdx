## What

One prompt takes an empty Vite project to your machine in the live viewer. A coding agent installs the packages, writes the machine and starts the dev server. You need Node.js 22.12 or later, a Vite project and a coding agent.

## Why

Writing the first machine, the Vite plugin and the viewer wiring by hand is setup before you see anything work. The skill gives the agent the conventions, so you describe the flow and get a running machine.

## How

```sh
# No Vite project yet:
npm create vite@latest my-app -- --template vanilla-ts
cd my-app && npm install
```

### 1. Install the skill

```sh
npx skills add AndersCan/mantaq -y
```

No skills support? Tell your agent to read https://anderscan.github.io/mantaq/llms.txt.

### 2. Tell your agent what to model

```text
Use the mantaq skill. A checkout that waits up to 30 seconds for payment and expires when time runs out, and a stock service that holds the item while checkout waits and lets it go when checkout expires. Set it up and open it in the live viewer.
```

Or describe your own flow in plain words.

A step that can time out: say how long it waits and what happens when time runs out, for example "payment expires after 15 minutes and the customer can pay again". Leave it out and the agent asks.

### 3. What you get

The agent installs `@mantaq/core`, `@mantaq/sugar` (for the 30-second timer) and `@mantaq/inspect`, writes `src/checkout.machine.ts` with both machines and the Vite plugin, and starts the dev server. The viewer is at `/__mantaq/?machine=checkout` on the port the dev server prints. Click the first arrow out of checkout's start state: the Step tab says what checkout sent to stock and where stock went.

The Vite config looks like this:

```ts
import { defineConfig } from "vite";
import { mantaqViz } from "@mantaq/inspect/vite";

export default defineConfig({
  plugins: [mantaqViz({ machines: "src/**/*.machine.ts" })],
});
```
