  An event moves the order from one state to another, and can carry data: `pay` carries an email,
  read as `event.payload`, and an empty one keeps the order in `cart`. Click `pay`. The finding that
  remains is `payment`, now a dead end. More in [Events](/mantaq/core-concepts/events/).
