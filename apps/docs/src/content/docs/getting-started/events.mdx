<Step n={3}>
  An event moves the person from one state to another, and can carry data: `eat` carries the food,
  read as `event.payload`. With no food the handler returns `{}`, which keeps them `hungry`;
  returning nothing does the same. Click `eat`: the person moves to `full`. More in
  [Events](/mantaq/core-concepts/events/).
</Step>
