## What

An event moves the person from one state to another, and can carry data.

## Why

Something outside the machine has to say that a change happened. Events are the only way in, so every transition has a name you can read, send and test.

## How

<Step n={3}>
  `eat` carries the food, read as `event.payload`. With no food the handler returns `{}`, which
  keeps them `hungry`; returning nothing does the same. Click `eat`: the person moves to `full`.
  More in [Events](/mantaq/core-concepts/events/).
</Step>
