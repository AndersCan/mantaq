## What

A region is a second state that runs beside the machine.

## Why

Thirst does not wait for the meal. Two independent parts as one flat machine need a state for every pair; a region keeps each part small.

## How

<Step n={9}>
  A region runs beside the meal, in its own state. `thirst` takes `drink` whatever the meal is
  doing.
</Step>
