## Requirements

- Node.js >= 22.12.0
- TypeScript >= 5.0

## Install

```bash
npm install @mantaq/core
# or
pnpm add @mantaq/core
```

Want helpers?

```bash
npm install @mantaq/sugar
# or
pnpm add @mantaq/sugar
```

Want viz?

```bash
npm install @mantaq/viz
# or
pnpm add @mantaq/viz
```

## What you get

```
@mantaq/core       →  Actor, state, event, VirtualClock, RealClock
@mantaq/sugar      →  Optional helpers. matches, states, events, tag, ActorMap, withPromise, withTimeout
@mantaq/viz →  MantaqViz web component (registers <mantaq-viz> custom element)
```

`sugar` and `viz` both need `core`. Only `core` required.

## TypeScript config

Standard config works. Nothing special needed:

```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ESNext",
    "moduleResolution": "bundler"
  }
}
```
