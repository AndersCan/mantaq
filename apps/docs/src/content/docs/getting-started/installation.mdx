## Requirements

- Node.js >= 22.12.0
- TypeScript >= 5.0

## Install

```bash
npm install @mantaq/core
# or
pnpm add @mantaq/core
```

Want helpers?

```bash
npm install @mantaq/sugar
# or
pnpm add @mantaq/sugar
```

## What you get

```
@mantaq/core       →  Actor, Context, state, event, VirtualClock, RealClock
@mantaq/sugar      →  Optional helpers. matches, states, events, tag, isIn, activeLeaves, ActorMap, broadcast, withPromise, withTimeout
```

`sugar` needs `core`. Only `core` required.

## TypeScript config

Standard config works. Nothing special needed:

```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ESNext",
    "moduleResolution": "bundler"
  }
}
```
