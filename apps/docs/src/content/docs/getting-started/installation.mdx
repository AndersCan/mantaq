## Requirements

- Node.js >= 22.12.0
- TypeScript >= 5.0

## Install

```bash
npm install @mantaq/core
# or
pnpm add @mantaq/core
```

Want helpers too?

```bash
npm install @mantaq/sugar
# or
pnpm add @mantaq/sugar
```

Want visualizer?

```bash
npm install @mantaq/visualizer
# or
pnpm add @mantaq/visualizer
```

## What you get

```
@mantaq/core       →  Actor, state, event, VirtualClock, RealClock
@mantaq/sugar      →  matches, states, events, tag, ActorMap, withPromise, withTimeout
@mantaq/visualizer →  ActorFlow, buildGraph, computeNodePositions
```

`sugar` needs `core`. `visualizer` needs `core`. Install all three for full API.

## TypeScript config

Standard config works. Nothing special needed:

```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ESNext",
    "moduleResolution": "bundler"
  }
}
```
