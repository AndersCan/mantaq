---
title: Viz
description: Visual state machine graph viewer for actors.
---

The visualizer renders actor state machines as interactive graph diagrams. States become nodes, transitions become labeled edges. Active states highlight. Supports pan, zoom, direction routing, and settings panel.

## Installation

```bash
npm install @mantaq/viz
```

## Usage

```html
<mantaq-viz id="my-viz"></mantaq-viz>

<script>
  import "@mantaq/viz";
  import { Actor, state, event } from "@mantaq/core";

  const idle = state("idle")();
  const running = state("running")();
  const start = event("START")();

  const actor = new Actor({
    inputs: [start],
    states: [idle, running],
    initial: idle,
    transitions: {
      idle: { START: () => ({ state: running }) },
    },
  });

  document.getElementById("my-viz").actor = actor;
</script>
```

Import the package once. The `<mantaq-viz>` element registers automatically. Set `.actor` to any `AnyActor` instance and it renders the full state machine graph.

## `<mantaq-viz>` Web Component

| Property | Type       | Description        |
| -------- | ---------- | ------------------ |
| `actor`  | `AnyActor` | Actor to visualize |

### Features

- **Toolbar** — shows current state name and available event buttons
- **Event buttons** — click to send events to the actor
- **Settings panel** — gear icon opens direction, router, and edge length controls
- **Pan and zoom** — mouse wheel zooms, click-drag pans
- **Active state highlighting** — blue stroke and background on active nodes
- **Final state indicator** — green stroke on final states
- **Effect edges** — dashed amber self-loops for pending effects/timers
- **Auto-sync** — re-renders on every actor state change

### Settings

| Control     | Options                                  |
| ----------- | ---------------------------------------- |
| Direction   | Top→Bottom (`TB`), Left→Right (`LR`)     |
| Router      | Normal, Orthogonal, Manhattan, Metro, ER |
| Edge length | Slider from 20 to 320 (default 100)      |

## Known Issues

- **Region grouping** — Child states of regions render at the same level as parent states without visual grouping.
