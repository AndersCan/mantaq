The visualizer renders actor state machines as interactive graph diagrams using X6 canvas rendering and Lit web components. States become nodes, transitions become labeled edges. Active states highlight. Supports pan, zoom, direction routing, and settings panel.

## Installation

```bash
npm install @mantaq/viz
```

## Basic Usage

### Web Component

```html
<mantaq-viz id="my-viz"></mantaq-viz>

<script>
  import "@mantaq/viz";
  import { Actor, state, event } from "@mantaq/core";

  const idle = state("idle")();
  const running = state("running")();
  const start = event("START")();

  const actor = new Actor({
    inputs: [start],
    states: [idle, running],
    initial: idle,
    transitions: {
      idle: { START: () => ({ state: running }) },
    },
  });

  const el = document.getElementById("my-viz");
  el.actor = actor;
</script>
```

### Programmatic Rendering

```ts
import { buildGraph, renderActorFlow } from "@mantaq/viz";

const graph = buildGraph(actor);
const container = document.getElementById("graph-root");

const instance = renderActorFlow(container, {
  graph,
  layoutOptions: { direction: "LR" },
  onEdgeClick: (eventName) => actor.send(eventName),
});

// Update later
instance.update(buildGraph(actor));

// Cleanup
instance.destroy();
```

## Features

### Graph Rendering

`buildGraph(actor, internalIds?)` converts an actor snapshot into graph data:

- **Nodes** — one per state, with `id`, `label`, `isActive`, `isFinal`, `isInitial`
- **Edges** — one per transition, labeled with event ID, with `source`, `target`, `isActive`
- **Active state highlighting** — active nodes render with blue stroke and light background
- **Final state indicator** — final states render with green stroke
- **Initial node** — automatic initial state indicator (circle node)
- **Effect edges** — internal/effect transitions render as dashed self-loops
- **Self-loops** — transitions to the same state render correctly

### Layout

`computeNodePositions(nodes, edges, opts?)` uses dagre for hierarchical layout:

- Topological sort places nodes in layers (default: top-to-bottom)
- Switch to `LR` direction for left-to-right layout
- Customize spacing via `nodesep` and `ranksep`
- Configure edge routing: `normal`, `orth`, `manhattan`, `metro`, `er`

### `<mantaq-viz>` Web Component

Self-contained custom element with toolbar, settings panel, and graph rendering.

| Property | Type       | Description        |
| -------- | ---------- | ------------------ |
| `actor`  | `AnyActor` | Actor to visualize |

Features:

- **Toolbar** — shows current state and available event buttons
- **Settings panel** — direction, router, edge length controls
- **Pan and zoom** — mouse drag and scroll wheel
- **Auto-sync** — re-renders when actor state changes

### Pan, Zoom, and Settings

Built into X6: mouse wheel zooms, click-drag pans. Settings gear icon opens direction/router/edge-length controls.

## Manual Layout

For custom positioning, use the exported layout function:

```ts
import { computeNodePositions } from "@mantaq/viz";

const positions = computeNodePositions(graph.nodes, graph.edges, {
  direction: "LR", // "TB" (default) or "LR"
  nodesep: 80, // horizontal gap between nodes
  ranksep: 160, // vertical gap between levels
  nodeWidth: 160,
  nodeHeight: 60,
});
// positions is a Map<string, {x, y}>
```

## API Reference

### `buildGraph(actor, internalIds?)`

```ts
function buildGraph(actor: AnyActor, internalIds?: Set<string>): ActorGraph;
```

Converts actor snapshot into graph nodes and edges. Returns `{ nodes: GraphNode[], edges: GraphEdge[] }`.

### `renderActorFlow(parent, options)`

```ts
function renderActorFlow(
  parent: HTMLElement,
  options: {
    graph: ActorGraph;
    layoutOptions?: LayoutOptions;
    onEdgeClick?: (eventName: string) => void;
  },
): ActorFlowInstance;
```

Creates an X6 graph instance in the parent element. Returns `{ update(graph, opts?), destroy() }`.

### `computeNodePositions(nodes, edges, opts?)`

```ts
function computeNodePositions(
  nodes: GraphNode[],
  edges: GraphEdge[],
  opts?: LayoutOptions,
): Map<string, { x: number; y: number }>;
```

Dagre-based hierarchical layout. Returns positions keyed by node ID.

### `collectActiveStates(snapshot, prefix, activeSet)`

```ts
function collectActiveStates(snapshot: Snapshot, prefix: string, activeSet: Set<string>): void;
```

Populates a Set with IDs of currently active states from a snapshot. Used internally.

## Known Issues

- **Region grouping** — Child states of regions render at the same level as parent states without visual grouping.
- **Edge detail** — Edge labels show event IDs. Guard conditions and action metadata parsed from handler source.
- **Layout simplicity** — Uses dagre. For complex graphs, consider manual positioning via `computeNodePositions`.
