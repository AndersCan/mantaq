---
title: Testing with Test Harness
description: Instrument actors, drive with events, assert coverage using @mantaq/test.
---

## What

`createTestHarness(actor)` from `@mantaq/test` instruments an actor and records every state visit, transition and effect.

## Why

Asserting the final state says nothing about the path. The record lets a test assert what ran and gate CI on what no test reached.

## How

### Setup

```ts
import { createTestHarness } from "@mantaq/test";

const { actor } = createCheckoutActor({ chargeCard: async () => "ord_1" });
const harness = createTestHarness(actor);
```

Use `harness.send()` instead of `actor.send()`. All sends are recorded.

### Drive and assert

```ts
harness.send(submitBasicInfo.create({ email: "a@b.com", name: "A" }));
harness.send(submitShipping.create({ street: "1 Main", city: "Oslo", zip: "0150" }));
harness.send(submitPayment.create({ cardNumber: "1111222233334444" }));
await actor.settled();

harness.assertStateVisited({ stateName: "basicInfo" });
harness.assertStateVisited({ stateName: "success" });
```

### Assertion methods

- `assertStateVisited({ stateName })` / `assertStateNeverVisited({ stateName })`
- `assertTransitionVisited({ from, event })` / `assertTransitionNeverVisited({ from, event })`
- `assertEffectRan({ stateName, effectName })` / `assertEffectNeverRan({ stateName, effectName })`
- `assertAllStatesVisited()` / `assertAllTransitionsVisited()`
- `assertContextNever({ predicate })` fails if predicate matches current context

### Query helpers

Non-throwing, return booleans:

```ts
harness.wasStateVisited("payment");
harness.wasTransitionVisited({ from: "payment", event: "submitPayment" });
```

### Coverage report

```ts
const report = harness.coverage();
// report.percent.states     — 0–100
// report.percent.transitions — 0–100
// report.states.uncovered    — string[]
// report.transitions.uncovered — Array<{ from, event }>
```

Use `report.percent` to gate CI. Use `uncovered` to find missing paths.

### Reset

`harness.reset()` clears history between test cases.
