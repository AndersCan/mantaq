The visualizer renders actor state machines as interactive graph diagrams. States become nodes, transitions become labeled edges. Active states highlight green. Supports pan, zoom, keyboard navigation, and dark mode.

## Installation

```bash
npm install @mantaq/visualizer
```

## Basic Usage

```ts
import { setActor, ActorGraphComponent, applyDefaultStyles } from "@mantaq/visualizer";

// Register the web component
customElements.define("actor-graph", ActorGraphComponent);

// Inject default styles into <head>
applyDefaultStyles();

// Pass your actor
setActor(myActor);
```

```html
<actor-graph></actor-graph>
```

## Features

### Graph Rendering

`buildGraph(actor)` converts an actor snapshot into nodes and edges:

- **Nodes** — one per state, with `id`, `label`, `isActive`, `isFinal`, `depth`
- **Edges** — one per transition, labeled with event ID, with `source`, `target`, `isActive`
- **Active path** — edges touching the current state highlight green
- **Self-loops** — states that transition to themselves render as loop-back edges
- **Wildcard transitions** — `Any` source creates edges to all states

### ELK.js Layout

`computeLayout(graph)` runs the ELK layered algorithm:

- Hierarchical left-to-right or top-to-bottom layout
- Bezier edge paths with arrow markers
- Self-loop path generation
- Backward edge detection
- Label midpoint positioning

### Pan and Zoom

Mouse wheel zooms toward cursor. Click-drag pans. Double-click fits graph to viewport.

### Keyboard Shortcuts

| Key       | Action      |
| --------- | ----------- |
| `+` / `=` | Zoom in     |
| `-`       | Zoom out    |
| `0`       | Reset view  |
| `F`       | Zoom to fit |

### Dark Mode

```ts
import { applyDarkTheme, removeDarkTheme } from "@mantaq/visualizer";

applyDarkTheme(); // toggle on
removeDarkTheme(); // toggle off
```

### Store (Nanostores)

Reactive state atoms for custom integrations:

| Atom              | Type                   | Purpose         |
| ----------------- | ---------------------- | --------------- |
| `$actor`          | `AnyActor \| null`     | Current actor   |
| `$graph`          | `ActorGraph \| null`   | Computed graph  |
| `$layout`         | `LayoutResult \| null` | Computed layout |
| `$selectedNodeId` | `string \| null`       | Selected node   |
| `$zoom`           | `number`               | Zoom level      |
| `$pan`            | `{x, y}`               | Pan offset      |
| `$layoutError`    | `string \| null`       | Layout error    |

Actions: `setActor`, `selectNode`, `zoomIn`, `zoomOut`, `zoomToFit`, `resetView`.

## Full Programmatic Example

To use the full visualizer with real actors (requires a bundler):

```ts
import { Actor, state, event } from "@mantaq/core";
import {
  setActor,
  ActorGraphComponent,
  applyDefaultStyles,
  startActorSync,
} from "@mantaq/visualizer";

// Define states and events
const idle = state("idle")();
const loading = state("loading")();
const done = state("done")().final();

const fetch = event("FETCH")();
const success = event("SUCCESS")();
const fail = event("FAIL")();
const retry = event("RETRY")();

// Create actor
function createFetcher() {
  return new Actor({
    inputs: [fetch],
    outputs: [],
    internal: [success, fail, retry],
    states: [idle, loading, done],
    initial: idle,
    context: {} as {},
    effects: {},
    transitions: {
      idle: { FETCH: () => ({ state: loading }) },
      loading: {
        SUCCESS: () => ({ state: done }),
        FAIL: () => ({ state: idle }),
      },
    },
  });
}

// Setup
customElements.define("actor-graph", ActorGraphComponent);
applyDefaultStyles();

const actor = createFetcher();
setActor(actor);

// Auto-sync: graph rebuilds when actor state changes
startActorSync();

// Trigger transitions
actor.send(fetch);  // idle → loading (graph updates)
actor.send(success); // loading → done (graph updates)
```

### Adding Transition Buttons

The visualizer renders the graph but does not yet provide built-in transition buttons. Wire them manually:

```ts
import { setActor } from "@mantaq/visualizer";

const actor = createFetcher();

// Find available transitions from current state
function getAvailableTransitions(a) {
  const snapshot = a.snapshot();
  const currentState = snapshot.path[snapshot.path.length - 1];
  const transitions = a.options.transitions[currentState] ?? {};
  return Object.keys(transitions);
}

// Render transition buttons
function renderButtons(a) {
  const container = document.getElementById("buttons");
  container.innerHTML = "";
  for (const eventId of getAvailableTransitions(a)) {
    const btn = document.createElement("button");
    btn.textContent = eventId;
    btn.addEventListener("click", () => {
      const events = { FETCH: fetch, SUCCESS: success, FAIL: fail };
      a.send(events[eventId]);
      setActor(a);  // re-render graph
      renderButtons(a);  // update available transitions
    });
    container.appendChild(btn);
  }
}

renderButtons(actor);
```

## API Reference

### `buildGraph(actor, options?)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `actor` | `AnyActor` | — | Actor instance |
| `options.nodeWidth` | `number` | `120` | Min node width |
| `options.nodeHeight` | `number` | `60` | Node height |
| `options.padding` | `number` | `20` | Node padding |

Returns `ActorGraph` with `nodes`, `edges`, `activePath`.

### `computeLayout(graph, options?)`

Async. Returns `LayoutResult` with positioned `nodes`, `edges`, `width`, `height`.

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `options.direction` | `"RIGHT" \| "DOWN"` | `"RIGHT"` | Layout direction |
| `options.nodeWidth` | `number` | `120` | Node width for ELK |
| `options.nodeHeight` | `number` | `60` | Node height for ELK |

### `setActor(actor)`

Sets actor in store, builds graph, triggers layout computation.

### `startActorSync()`

Subscribes to `$actor` changes. Returns unsubscribe function. Call after `setActor` for live updates.

## Known Issues

:::note[Missing Features]
- **Transition trigger buttons** — No built-in UI to send events from the graph. Must wire manually (see example above).
- **Live actor sync** — `startActorSync()` exists but not called automatically. Graph does not update when actor state changes unless consumer calls `setActor` again.
- **Store-component wiring** — `ActorGraph` component accepts props but does not subscribe to nanostores. Missing `@nanostores/lit` integration. Consumer must bridge store values to component props manually.
- **Region labels** — Sub-region wrapper nodes not rendered. States display directly under parent without visual grouping.
- **Edge labels** — Shows event IDs only. Guard conditions and action metadata not displayed.
:::
