## What

The visualizer draws a machine as a graph and lets you walk it. States are nodes, transitions are edges.

## Why

Reading handlers shows what one state does. The graph shows every path, and walking it shows which step you can take next. The visualizer reads a viz document made from your machine; it does not run your handlers unless you use the live page.

### Walking the graph

The viewer keeps a cursor on one state, starting at the initial one. Pulsing edges are the steps you can take next. A click on a state or an edge selects it and shows it in Details; it never takes a step. Take a step with a **Send** button in the Step tab.

In an actor map the diagram shows the child machine once. Live, each child is a chip with its key on the state it is in, and the Step tab lists every child with its own Send buttons. Click a chip to follow that child: its row is marked, and an arrow's Send in the map goes to it.

The selected arrow's Details has the same **Send** button when the walk is in its source state. After a Send from there, Details say what was sent, with its values, and where it went. An arrow selects wherever its line is clicked, dashed and dotted ones included.

The panel groups the next steps:

- **Send an input**: edges on input events.
- **Effect reports back**: internal events that an effect of the current state declares in `sends`.
- **Other internal events**: internal events that no effect of the state declares.

On the live page every event has a Send button in the Step tab. Effects do not run there: the answers of `submitting` (`paymentOk`, `paymentFail`, `paymentTimeout`) are the arrows out of it. The initial state's effects run while the machine is built.

A final state ends the walk. **Back** and **Reset** undo steps. `?machine=checkout&run=<name>` opens a recorded run by name; use it for links in docs and issues.

On the live page (the Vite plugin) each step runs the real actor, so guards are evaluated.

### Nodes

| Style                                         | Meaning                                                                   |
| --------------------------------------------- | ------------------------------------------------------------------------- |
| Box                                           | A state                                                                   |
| Double border                                 | A final state                                                             |
| Thick border                                  | The state the walk is on                                                  |
| Dot and arrow on the left                     | The initial state                                                         |
| Dashed box `*`                                | An `onAny` registration: any non-final state                              |
| Dashed box (no label)                         | A state a next step reaches                                               |
| Pill inside a state                           | An effect the state runs on entry, by name (`chargeCard` in `submitting`) |
| Dashed circle `?`                             | An unknown target                                                         |
| Shaded rectangle                              | A region: its own start arrow and current state                           |
| Box titled `<map>: one per key`               | An actor map: one child machine                                           |
| Dark chip with a key at the bottom of a state | A live child of an actor map, by key                                      |

### Edges

| Style                      | Meaning                                            |
| -------------------------- | -------------------------------------------------- |
| Solid arrow                | A transition on an input event                     |
| Dotted arrow, italic label | A transition on an internal event                  |
| Dotted self-loop           | The event is handled and the state does not change |
| Dashed orange arrow        | Undetermined target                                |
| Green arrow                | Seen only while fuzzing, not declared              |
| Pulsing dashed arrow       | A step you can take next                           |
| Teal arrow                 | The arrow selected in Details                      |
