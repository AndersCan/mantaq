## When the app and the model disagree

## Events with data

An event with data needs sample payloads; walks pick among them.

```ts
payloads: { setCount: [{ count: 0 }, { count: 3 }] },
```

## Async apps

Adapters may return promises. Write an async result the app waits for as a model event: the adapter makes it happen, then awaits the app. Pass a timeout to `test` for slow apps.

```ts
save: (app) => { app.save(); },
saveFinished: async (app) => { backend.finish(); await app.saving; },
```
