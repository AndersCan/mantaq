## Why Mantaq?

<CardGrid stagger>
  <Card title="Tiny API" icon="star">
    Three things: `state`, `event`, `Actor`. Learn them, build anything.
  </Card>
  <Card title="Fully Typed" icon="document">
    Events, states, context — all inferred. No manual type annotations.
  </Card>
  <Card title="Testable" icon="add-document">
    `VirtualClock` makes time deterministic. No fake timer hacks.
  </Card>
  <Card title="Hierarchical" icon="setting">
    Regions, parallel states, final states. Complex patterns, simple API.
  </Card>
</CardGrid>
