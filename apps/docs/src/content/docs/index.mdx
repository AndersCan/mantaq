Mantaq is a state machine library for TypeScript. You describe a flow as a set
of states and the events that move between them, and Mantaq handles the rest:
transitions, side effects, timeouts, child actors, and cleanup. Everything is
typed from your declarations, so an event you never declared won't compile.

These docs build one running example — a multi-step checkout form — and grow it
across every page.

## Why Mantaq?

<CardGrid stagger>
  <Card title="Tiny API" icon="star">
    Three things: `state`, `event`, `Actor`. Learn them, build anything.
  </Card>
  <Card title="Fully Typed" icon="document">
    Events, states, context — all inferred. No manual type annotations.
  </Card>
  <Card title="Testable" icon="add-document">
    `VirtualClock` makes time deterministic. No fake timer hacks.
  </Card>
  <Card title="Hierarchical" icon="setting">
    Regions, composition, final states. Complex patterns, simple API.
  </Card>
</CardGrid>
