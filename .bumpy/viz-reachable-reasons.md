Without a panel, an arrow that sends nothing now has a `?`. A click or Enter on the `?` puts the reason in the line under the board, so keyboard and touch users can read it. An arrow that sends has no `?`. A shared arrow with no member at the current state now says why on hover and through its `?`. On a folded machine, a shared node reads "any state" only when every open state of each group takes the event, and it is marked current only while the walk is in a state that takes it.
